
    CSS
    * Stands for Cascading style Sheet
    * Used to increase standards and overall look of web page to make it presentable.
    * With CSS user can understand the web page content easily by making UI as rich.
    * History:
          -> CSS invented in W3C(consortism) on 17th dec,1996 by Hakon Wiem Lie

    * Uses
        -> Improves looks.
        -> Separates content and design.
        -> Maintains consistancy across multiple pages.
        -> Makes web pages as responsive for different types of devices(mobiles,tablets,laptop).
        -> Reduce code duplication .
        -> Adds visuals effects like animation, transition, transformation.

    * How to use CSS?
        selector {
            prop : value;
        }   
           -> Selector: Targetting HTML elements by using its name, id , class.
           -> Declaration block contains one or more CSS declaration separated by ";".
           -> One declaration contains css property name and value separated by ":"
           -> We cant write duplicate css property in same declaration block, if it is so always last occurance
              will executes (** overides)

     * How CSS Works 
      -> When CSS loaded into the browser, tree like structure called CSSOM (Cascading style sheet object models)
       will be created after parsing css in browser.
      -> Just like as the browser converts HTML into a DOM (Document Object Model), it converts CSS into CSSOM.
      -> Later browser will combines both DOM and CSSOM to create a render tree.

     * Types of CSS
         1. Inline CSS:
               -> Writing css property by using "style" attribute into the html element.
               -> Syntax: 
                   <h1 style="color:'blue'; font-size: '30px'"></h1> 
               -> Advantages:
                    => Good for small changes.
                    => It is having high priority.
               -> Disadvantages:
                     => It is required to apply for each and every html element.
                     => Not reusable.

         2.Internal CSS: 
              -> Writing the css property inside <style> tag in the HTML Document.
              -> Advantages :
                  >> Reusable
                  >> Easy to access
                  >> Better for single pages.
              -> Disadvantages:
                  >> Can't reuse across multiple pages.

          3.External CSS: 
               -> keeping styling property in separate CSS file.
               -> Can be connected to html using <link> tag.
               -> Advantages :
                    >> Can be used across multiple web pages.
                    >> Most recomended
                    >> Easy to maintain.     
        

        => Box Model 
             * The CSS Box Model consists of content, padding, border, and margin. It defines the layout and 
               spacing of elements, and the total size of an element is calculated using these 
               properties.
                         Margin 
                            |_ Border 
                               |_ padding
                                  |_ content
             * Every element = a box of 4 layers:
                  content -> actual text/image
                  padding -> space inside the box(around content)
                  Border  -> edge of the box
                  Margin  -> space outside the box 
             * Total Width Calculation 
                 Total width = content + padding + border + margin
             * Why it is important 
                  Controls layout and spacing
                  Helps avoid design issues
                  Essential for responsive design.

        Psuedo-class
        * psuedo classes are used to change the state of whole HTML element.
        * Can change the state of elements on the basis of links availability, user interaction, position of element
          on the DOM and more
        * Syntax:
             selector: psuedo-class{
                css prop
             }   
        * Types: 
            1.link : To change the state of unvisited links on the web page.
            2.visited : To change the status of visited links.
            3.active : To change the status of active links(When user click and hold on link)
